# GameForge Lite 2.1.1

GameForge Lite 是一个完全在浏览器本地运行的 Minecraft Java 1.20.1 创作工作室。普通玩家可以通过一句话、表单和模板生成数据包、资源包、指令函数、低代码 Forge JAR 与 Forge 源码，不需要服务器、数据库、API Key 或付费 AI。

## 主要功能

- 一句话本地解析：覆盖武器、Boss、方块、世界、维度、群系、地形、天气、结构、规则、事件、任务、魔法、科技和玩法系统
- 386 个基础语义概念、4,500 多个中英文直接表达和约 80,000 种可组合表达
- 额外 4,017 条高优先级词语与短语，运行时形成 6,402 个有效匹配形式
- 自定义武器、物品、食物、装饰方块、生物与 Boss
- 高级命中武器：目标分类、一击必杀、低生命斩杀、倍率伤害、额外伤害、吸血、击退和状态效果
- 指令、配方、掉落表、函数与进度生成器
- 资源包物品生成器与像素纹理编辑
- Forge 1.20.1 工具、物品、食物和方块源码生成
- 项目保存、复制、导入、导出、文件预览与完整 ZIP 下载
- 浏览器本地 ZIP → Forge 1.20.1 低代码 JAR 转换
- GameForge Runtime 0.3.0：精确命中机制与响应式 JEI 风格内容浏览器
- 游戏内首次进入初始化、普通玩家菜单、配方自动解锁与完整操作入口
- 自动诊断、浏览器自测、日志错误分析与 PWA 离线缓存
- 重复 ID、CustomModelData 和 ZIP 路径自动避让

## 本地提示词词库

本地词库不调用 AI，也不会上传玩家输入。它把中文、英文、口语、繁体和同义表达映射为统一概念，再交给现有生成器或概念草案系统处理。

词库分为两层：

- **基础语义层**：386 个概念、4,500 多个直接别名，以及由句式组合产生的约 80,000 种表达。
- **词语与参数扩展层**：4,017 条源词语与短语、6,402 个有效匹配形式、183 个 Minecraft 物品别名、70 个生物与 Boss 别名、16 类数值参数和 15 组颜色表达。

当前覆盖：

- 创作意图：创建、修改、删除、扩展、组合、复制、转换和随机生成
- 内容类型：物品、武器、盔甲、工具、食物、方块、家具、机器、生物、宠物、NPC 和 Boss
- 大型内容：世界、维度、群系、地形、洞穴、海洋、天空岛、废土、城市、村庄、地牢、神殿和传送门
- 环境系统：昼夜、永昼、永夜、黄昏、雨雪、雷暴、酸雨、灰烬、沙尘暴、流星雨、雾、温度和重力
- 玩法系统：生存、RPG、塔防、波次、尸潮、缩圈、任务、剧情、商店、经济、职业、阵营、声望、技能树和胜利条件
- 主题风格：奇幻、黑暗、末日、赛博朋克、蒸汽朋克、修仙、克苏鲁、太空、海洋、冰雪和火山
- Minecraft 表达：数据包、资源包、Forge、Fabric、NeoForge、NBT、CustomModelData、配方、掉落表、函数、进度和世界生成

示例：

```text
给我整一个永夜酸雨废土世界，每七天来一波强化尸潮
create a cyberpunk dimension with low gravity and meteor storms
做一把右键召唤闪电、冷却5秒的太刀
做一把叫亡灵剑的剑，命中时秒杀亡灵生物，不伤害玩家
做一把猎尸剑，只对僵尸造成三倍伤害
做一把收割镰刀，命中敌对生物时，血量低于20%直接斩杀
创建一个叫传送核心的物品，基础材料是末影珍珠，蓝色发光
做一只叫沙漠猎手的尸壳，HP八十，攻击力九
```

词库负责“听懂并标准化”。识别出世界、维度或大型系统，不代表对应生成器已经全部实现；未实现内容会保存为概念草案，而不是被误生成成普通武器或方块。

## 精确高级武器机制

高级武器提示词会保存标准化元数据，例如：

```json
{
  "trigger": "on_hit",
  "effect": "instant_kill",
  "targetGroup": "undead",
  "targetEntity": "",
  "affectPlayers": false,
  "affectTamed": false,
  "runtimeRequired": true,
  "mechanicVersion": 1
}
```

支持的目标包括：

- 亡灵、敌对、水生、节肢、灾厄村民、动物、Boss 和玩家
- 僵尸、骷髅、尸壳、溺尸、凋灵骷髅、蜘蛛、苦力怕等具体实体
- 任意生物，并可明确排除玩家或驯服宠物

支持的精确命中效果包括：

- 一击必杀
- 低生命百分比斩杀
- 倍率伤害和额外固定伤害
- 生命偷取和强力击退
- 凋零、燃烧、中毒、冻结、闪电和安全爆炸效果

Runtime 0.3.0 使用 Forge 服务端 `LivingDamageEvent` 读取真实攻击者、玩家手中的 GameForge 武器与真实受击实体。它不会再通过“附近最近实体”猜测命中目标，因此多个怪物靠在一起时也不会把技能错误施加给另一只怪。

安全默认值：

- 高风险技能默认不作用于玩家
- 默认不作用于攻击者自己的驯服宠物
- 只有提示词明确要求 PvP 或宠物目标时才开放
- “蜘蛛剑”这样的武器名称不会被误判为“只攻击蜘蛛”
- “不伤害玩家”只被视为安全排除条件，不会被误判为玩家目标

## 作品游戏内核心机制

每个包含低代码内容的项目都会生成 GameForge 核心运行时函数：

- 第一次进入世界时自动初始化并显示项目菜单
- 使用 `/trigger`，普通玩家无需管理员权限即可点击操作
- 一键获取全部武器、物品、资源物品和装饰方块
- 一键召唤全部生物和 Boss
- 自定义配方自动加入玩家配方书
- 普通武器支持右键、命中和被动触发，以及冷却和 Tick 机制
- 精确高级命中技能由 Runtime 0.3.0 服务端事件处理
- 目标型技能在没有目标时不会错误消耗冷却
- 装饰方块在生存模式放置时消耗物品，并可回收最近方块
- 掉落表可直接测试，并可应用到最近实体或脚下容器
- 提供全部获取、全部召唤、诊断、清理和卸载函数

常用函数：

```mcfunction
/function 命名空间:gameforge/menu
/function 命名空间:gameforge/get_all
/function 命名空间:gameforge/spawn_all
/function 命名空间:gameforge/cleanup
/function 命名空间:gameforge/doctor
/function 命名空间:gameforge/uninstall
```

## GameForge Runtime GUI 0.3.0

Runtime 是与网站配套的独立 Forge Mod。把 Runtime JAR 和作品 JAR 放进同一个 `mods` 文件夹，进入世界后按 `G` 打开。

### 精确高级武器

- 扫描作品 JAR 中的 `META-INF/gameforge/project.json`
- 精确识别实际攻击者、主手 GameForge 武器和真实受击实体
- 按目标组或具体实体判断技能是否触发
- 使用每位玩家、每件武器独立的冷却状态
- 在动作栏显示技能名称、效果摘要和真实目标
- 闪电使用视觉闪电，爆炸使用粒子与安全直接伤害，避免破坏方块或误伤范围内玩家

### 内容浏览器

- 扫描所有已安装的 GameForge 作品 JAR
- 以图标网格浏览武器、物品、方块、生物、Boss 和有配方内容
- 按名称、作品名、命名空间、内容 ID、基础材料、触发方式和技能效果搜索
- 使用真实 ItemStack 和 `CustomModelData` 显示作品模型
- 显示伤害、攻速、生命、护甲、载体、技能、冷却、范围和其他属性
- 内置 3×3 配方查看器，显示最终 GameForge 物品，而不是知识之书中转结果
- 一键获取单件物品或召唤单个生物与 Boss
- 支持项目菜单、获取全部、召唤全部、诊断和清理
- 检测重复作品命名空间，提醒删除旧 JAR 副本
- 简体中文与英文界面

### 响应式布局

Minecraft 的 GUI Scale 会把高分辨率显示器缩成较小的逻辑坐标。Runtime 会读取 GUI 缩放后的宽度和高度：

- 逻辑宽度低于 760，或逻辑高度低于 430 时，自动打开紧凑布局
- 紧凑布局使用图标网格，不把名称塞在每个格子下面
- 当前物品名称、ID 和“获取／配方／详情”移动到底部独立操作条
- 属性详情和九宫格配方使用独立全宽页面，不再与搜索栏、分类栏重叠
- 作品管理、兼容诊断、帮助和底部状态栏也使用紧凑排版
- 较大的逻辑屏幕继续使用完整双栏浏览器

Runtime 只负责 **GameForge 作品内容**，不会代替 JEI 对原版和其他第三方 Mod 的完整索引。推荐同时安装：JEI 管理整个模组包，Runtime 准确展示并操作 GameForge 低代码内容。

下载文件：

```text
gameforge-runtime-1.20.1-0.3.0.jar
```

升级时请删除旧版 Runtime，只保留一个版本。多人游戏需要客户端和服务端安装相同版本的 Runtime 与作品 JAR。

## ZIP → JAR

工作室右下角提供 `ZIP → JAR`：

1. 识别 `datapack/data`、`resourcepack/assets` 和 `project.json`。
2. 把数据包和资源包合并到 JAR 根目录的 `data/` 与 `assets/`。
3. 自动补全 `pack.mcmeta`、`META-INF/mods.toml` 和 `META-INF/MANIFEST.MF`。
4. 使用 Forge 1.20.1 的 `lowcodefml`，不编译任意 Java 源码。
5. 重新打开生成结果，检查必要文件、目录结构、JSON、PNG、Mod ID 和 `pack_format: 15`。
6. 验证通过后才下载；整个过程留在浏览器本地。

转换器会检查作品是否包含 `runtimeRequired: true` 的精确命中技能：

- 有高级命中技能时，生成的 `mods.toml` 会声明 GameForge Runtime 0.3.0 或更高版本为必要依赖
- 普通作品不会被错误标记为强制依赖 Runtime
- 上传 ZIP 后会明确列出哪些组件需要 Runtime
- 多人作品会提示客户端与服务端必须安装相同版本

单组件作品的 JAR 默认使用武器、物品、生物或其他组件名称；多组件作品使用作品名称。更新同一作品时必须删除旧 JAR，只保留最新一个，避免相同 Mod ID 和命名空间冲突。

## 兼容边界

- 官方目标：Minecraft Java 1.20.1、Forge 47.x、Java 17
- 精确高级命中技能要求 GameForge Runtime 0.3.0 或更高版本
- 多人游戏需要客户端和服务端安装相同版本的 Runtime 与作品 JAR
- 低代码 JAR 不注册真正的新物品 ID；它使用原版载体、CustomModelData、函数和配方
- Runtime 准确展示 GameForge 元数据和作品配方，但不是 JEI 对所有第三方 Mod 的完整替代品
- 真正的新物品、方块、复杂 GUI、网络同步和其他 Java 事件仍使用 Forge 源码导出
- 世界、维度、结构和大型系统会随着对应生成模板逐步实现
- 爆炸、循环函数、大范围命令和自定义实体应先在复制的测试世界运行

## 测试状态

网站构建会检查 JavaScript、页面、移动端布局、JSON、ZIP、项目导入导出、Forge 源码结构、JAR 生成、本地词库和核心运行时。高级武器回归测试覆盖亡灵秒杀、僵尸三倍伤害、敌对生物低血量斩杀、右键雷电兼容、武器名称误判、玩家安全排除、明确 PvP 目标和精确 Runtime 元数据导出。

Runtime 0.3.0 使用 Java 17 与 Forge 47.4.21 编译，自动验证 JAR 结构、版本字符串、`AdvancedWeaponHandler`、桌面浏览器、紧凑浏览器、网络操作、语言文件和物品模型工厂。自动测试无法完全代替真实 Minecraft 行为测试，最终仍应在复制的 Forge 1.20.1 世界中验证。
