这次专门解决“小逻辑屏幕”问题

你的显示器分辨率并不低，但 Minecraft GUI Scale 3 会把可用坐标缩小到大约五百多像素宽。0.2.1 不再把桌面双栏硬塞进去，而是切换为真正的紧凑布局。

↔

自动选择布局

根据 GUI 缩放后的宽度和高度判断，不需要玩家手动切换模式。

▦

图标网格优先

紧凑模式只在网格中显示物品图标，名称和操作放在独立底栏。

≡

详情单独成页

属性不再塞在右侧窄栏里，点击“详情”后使用完整内容区域展示。

3×3

配方单独成页

九宫格、输出物品和说明拥有自己的页面，不会与搜索栏或分类栏重叠。

✓

其他页面也压缩

作品管理、兼容诊断、使用帮助和底部状态栏都增加了紧凑布局。

JEI

原有功能保留

搜索、分类、悬停提示、一键获取、召唤、配方和诊断仍然可用。

替换旧版即可测试

请不要同时保留 0.2.0 和 0.2.1，否则 Forge 会报告重复 Mod ID。

完全关闭 Minecraft 和 PCL 正在运行的游戏实例。
从 mods 删除 gameforge-runtime-1.20.1-0.2.0.jar。
放入 gameforge-runtime-1.20.1-0.2.1.jar，作品 JAR 只保留最新一个。
重新启动游戏，进入世界后按 G。
