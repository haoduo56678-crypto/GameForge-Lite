真正补齐 GameForge 作品的使用入口

这不是复制 JEI 全部生态的替代品，而是针对 GameForge 低代码作品补上 JEI 最重要的浏览、搜索、配方和获取体验。

⌕

跨作品搜索

按名称、ID、基础材料、技能效果和命名空间搜索所有已安装的 GameForge 内容。

▦

图标网格与分类

按武器、物品、方块、生物、Boss 和有配方内容筛选，支持滚轮浏览。

⚔

属性详情

显示伤害、攻速、生命、护甲、载体、CustomModelData、触发方式、效果与冷却。

3×3

内置配方查看

直接展示九宫格材料和最终自定义物品，不再让玩家只看到知识之书中转结果。

+

一键获取或召唤

选中物品即可获取，选中生物或 Boss 即可召唤；服务端只执行白名单函数。

✓

兼容诊断

检查作品数量、可浏览内容、配方和重复命名空间，提醒删除旧 JAR 副本。

安装一次，管理以后所有作品

Runtime 是独立 Forge Mod。升级时请删除旧版 Runtime，只保留一个最新 JAR。

下载 gameforge-runtime-1.20.1-0.2.0.jar。
删除 mods 文件夹中的 Runtime 0.1.0 或其他旧副本。
把新 Runtime 和网站生成的作品 JAR 放进同一个 PCL 实例 mods 文件夹。
完全重启 Minecraft，进入世界后按 G。
