# GameForge 本地内容目录

GameForge 的内容目录解决一个最直接的问题：玩家不应该为了生成一个箱子、火把、弓、狐狸或工作台，先学会写“物品”“方块”“EntityType”等开发词。

## 目录规模

当前目录由程序化家族和人工校对条目组成，构建时至少包含：

- 800 个以上的标准内容条目；
- 9,000 个以上的中文、繁体中文、英文和 Minecraft ID 匹配形式；
- 700 个以上可以直接使用原版物品、方块或实体作为可靠底座的条目；
- 80 个以上的家具、机器、枪械、魔法、载具、幻想生物和大型系统概念。

覆盖范围包括木材家族、16 色方块家族、建筑材料、储物与工作站、红石、矿石、工具、武器、盔甲、食物、交通、常见物品、原版生物，以及大量非原版创作对象。

## 基础内容怎么生成

例如：

```text
生成一个箱子
给我一把弓
做一个火把
生成一张床
做一个指南针
生成一只狐狸
来一个红色潜影盒
```

系统会直接找到对应的 Minecraft 1.20.1 内容，并创建可获得、可使用或可召唤的组件。用户不需要补写“这是一个物品”或“这是一个方块”。

`生成一个箱子` 会使用 `minecraft:chest` 作为实际载体，而不是只把能力提示变成绿色。

## 不只识别基础物品

目录也识别：

- 家具：椅子、桌子、沙发、柜子、冰箱、电视、电脑等；
- 工业机器：粉碎机、压缩机、发电机、核反应堆、涡轮机等；
- 枪械：手枪、步枪、霰弹枪、激光枪、火箭筒等；
- 魔法：法术书、符文、祭坛、护符、魔法戒指等；
- 载具：汽车、飞机、坦克、火箭、宇宙飞船、机甲等；
- 幻想实体：巨龙、凤凰、狮鹫、机器人、恐龙、外星生物、NPC 等；
- 大型系统：任务、对话、经济、商店、技能树、能源网络、匹配和大厅等。

这些内容不会被全部标成绿色。目录会结合现有生成器给出真实状态：

- 家具可以先生成装饰外观；
- 核反应堆可以先生成通用机器、GUI、存档和处理流程，但不会自动拥有完整核能系统；
- 激光枪可以先生成可用的远程载体，但不会自动拥有完整弹匣、换弹、后坐力和自定义子弹；
- 汽车可以先生成装饰模型，但当前不会变成可驾驶载具；
- 任务、经济和技能树会保存需求，但当前不会伪装成完整可玩系统。

## 上下文优先级

同一个词在不同句子里不能被粗暴地当成普通物品：

```text
生成一个箱子           → 箱子内容
箱子掉落钻石           → 掉落表
9 个木板合成箱子       → 配方
做一个箱子 Boss        → 生物 / Boss
做一个有箱子的世界     → 世界与维度
```

目录只负责补足内容名识别；配方、掉落、世界、机器和实体等专业生成器仍然优先。

## 维护要求

新增 Minecraft 内容或 GameForge 能力时，需要同时更新：

1. 标准条目和别名；
2. 实际生成路线；
3. 绿色、黄色、灰色或红色状态；
4. 上下文冲突测试；
5. 真实生成结果测试。

“认识一个词”不等于“完整实现一个系统”。目录的目标是扩大输入范围，同时继续保持能力说明诚实、直白。
