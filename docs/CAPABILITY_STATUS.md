# GameForge 能力状态说明

GameForge 在创建和下载前，会直接告诉用户：**最终会生成什么，不会生成什么。**

页面不要求普通玩家理解 IR、后端、Pipeline、注册表等开发术语。状态只使用四种颜色和四句直白的话：

| 颜色 | 页面文字 | 实际意思 |
|---|---|---|
| 绿色 | **会生成** | 会输出对应内容，可以继续测试和运行 |
| 黄色 | **只能做一部分** | 会生成基础部分，但不会完成用户描述的全部功能 |
| 灰色 | **只会记下来** | 会保存需求，方便以后继续编辑，但不会生成可玩的逻辑 |
| 红色 | **现在做不了** | 当前既不会生成对应功能，也不会假装已经完成 |

## 页面必须怎么说

每次分析都先显示：

> 下面告诉你最终会生成什么，不会生成什么。

然后给出一条完整结果，例如：

> 最终会生成：一个有基础属性和基础行为的 Boss。不会生成：阶段切换、飞行寻路。

不能只写：

```text
Boss：Partial
Flight AI：Unsupported
```

因为普通玩家不应该自己猜这些词最后代表什么。

## 示例

### 多阶段飞行 Boss

输入：

```text
做一个多阶段飞行 Boss
```

页面应显示：

```text
绿色：基础 Boss——会生成
灰色：多阶段 Boss——只会记下来
红色：飞行 AI 和飞行寻路——现在做不了

最终会生成一个普通 Boss，不会生成阶段切换和飞行寻路。
```

### 酸雨尸潮世界

输入：

```text
做一个酸雨世界，每七天来一波强化尸潮
```

页面应显示：

```text
绿色：新世界和可进入维度——会生成
绿色：地形预设——会生成
灰色：特殊天气事件——只会记下来
灰色：尸潮、波次或塔防——只会记下来

最终会生成一个可以进入的新维度，但不会自动出现酸雨和七天尸潮。
```

### 工业机器

输入：

```text
做一个输入铁锭和煤炭、输出金锭的机器
```

页面应显示：

```text
绿色：真正的机器方块——会生成
绿色：机器界面——会生成

最终会生成一台能放置、能保存物品、能处理配方并能打开界面的机器。
```

### Fabric 1.21 匹配大厅

输入：

```text
生成 Fabric 1.21 的匹配大厅 Mod
```

页面应显示：

```text
红色：Fabric 工程——现在做不了
红色：其他 Minecraft 版本——现在做不了
红色：通用多人玩法框架——现在做不了

当前没有可生成的内容，请返回修改需求。
```

## 显示位置

能力状态会出现在：

- 主页一句话创建框下方
- 原生机器与实体工作室
- 世界与维度工作室
- Blueprint 页面
- 原生 Forge 工程页面
- 创建前确认窗口
- 下载前确认窗口
- 生成作品中的 `README_CAPABILITY_STATUS.txt`
- 生成作品中的 `gameforge-capability-report.json`

## 下载规则

- 全部为绿色：可以直接继续，不额外打断用户。
- 有黄色、灰色或红色：下载前再次显示最终效果，用户明确确认后才能继续。
- 只有灰色或红色、没有任何可生成内容：不允许创建一个误导性的空作品。

## 维护规则

每次新增生成能力时，需要同时更新：

1. 能力识别规则；
2. 页面直白说明；
3. 生成报告；
4. 回归测试；
5. README 或对应功能文档。

一个词被词库识别，不等于对应功能已经实现。状态必须以**最终实际输出**为准。
