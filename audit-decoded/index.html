Guide
学习与安装
你不需要先学会全部原理，但这里会告诉你生成的文件在做什么，以及出错时先看哪里。

        

          
        

        

          
1
数据包
把下载的 ZIP 放入 .minecraft/saves/世界名/datapacks，进入世界后执行 /reload。
2
资源包
把资源包 ZIP 放入 .minecraft/resourcepacks，在游戏设置中启用，并放在其他冲突资源包上方。
3
获得作品
工作区的安装说明会列出给予或召唤函数，例如 /function 命名空间:weapon/id/give。
4
多人世界
数据包装在服务器世界里；资源包需要每名玩家启用，或由服务器设置资源包下载地址。

        

        
pack.mcmeta描述版本data/minecraft/tags/functions/注册 load 与 tickdata/你的命名空间/functions/存放指令函数data/你的命名空间/recipes/存放配方 JSONdata/你的命名空间/loot_tables/存放掉落表
为什么使用模板生成？
模板能保证目录与 JSON 结构稳定；智能解析只负责把你的描述转换成字段，不直接随意编造整套代码。

        
pack.mcmeta资源包版本assets/minecraft/models/item/基础物品.json根据 CustomModelData 切换模型assets/命名空间/models/item/id.json自定义模型assets/命名空间/textures/item/id.png自定义纹理
资源包冲突
两个资源包都修改同一个基础物品模型时，排序靠上的会覆盖下面的。GameForge 会在同一个项目里自动合并 overrides，但无法自动合并其他作者的资源包。

        
1
安装 64 位 JDK 17，并确认 PowerShell 中 java -version 显示 17。
2
解压 Forge 源码 ZIP，右键运行 setup-windows.ps1，它会下载推荐 MDK 的 Gradle Wrapper。
3
运行 run-client.bat 启动开发客户端测试。
4
运行 build-mod.bat，JAR 会出现在 build/libs。
IDE 可选
想看懂或继续修改代码，可以用 IntelliJ IDEA 或 VS Code；只体验生成结果时，可以先直接运行脚本。
