怎么使用

        
    
          
  1. 选择左边的工具并填写内容。
    2. 
          
  2. 先点击“生成”或“预览”，确认 JSON / 指令。
    3. 
          
  3. 下载 ZIP。
    4. 
          
  4. 数据包放进世界目录的 datapacks；资源包放进游戏目录的 resourcepacks。
    5. 
          
  5. 进入游戏后执行 /reload。
    6.
